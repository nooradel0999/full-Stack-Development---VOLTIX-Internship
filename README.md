# full-Stack-Development---VOLTIX-Internship

1. Project Overview
This project is a professional Company Landing Page developed as part of the Full Stack Development VOLTIX Internship program. The landing page was built for a fictional technology company named "NexaTech Solutions" to demonstrate modern web development skills including HTML5, CSS3, and JavaScript.
The page follows industry best practices for landing page design in 2026, incorporating clear messaging, strong CTAs, social proof, mobile-first responsive design, and optimized performance.
Project Objectives
•	Create a professional and visually appealing landing page
•	Implement responsive design for mobile, tablet, and desktop
•	Organize project files and code in a clean, maintainable structure
•	Ensure easy navigation and excellent user experience
•	Pay attention to UI details and design quality

The landing page consists of the following main sections, each designed to serve a specific purpose in the user journey:

Fixed top navigation with smooth scroll links, logo, and CTA button. Includes mobile-responsive hamburger menu.

Full-screen hero with background image, headline, subheadline, dual CTAs, animated statistics counters, and floating cards.

Company introduction with image, experience badge, features grid, and call-to-action.

6. Responsive Design
The landing page is fully responsive and optimized for all screen sizes using a mobile-first approach. The following breakpoints are implemented:
Desktop (1200px+)
Full layout with all features, multi-column grids, and maximum content width of 1280px.
Laptop (992px - 1199px)
Adjusted grid layouts, reduced font sizes, and optimized spacing.
Tablet (768px - 991px)
Two-column grids, stacked hero section, hamburger menu, and adjusted padding.
Mobile (< 768px)
Single-column layout, full-width buttons, hidden floating cards, centered content, and thumb-friendly touch targets.
Small Mobile (< 480px)
Further reduced font sizes, compact spacing, and optimized form fields.
